# VM — панель хозяина

`warfare-launcher.py` открывает одно развёрнутое окно без вкладок. Интерфейс — русский или английский. F11 переключает полный экран, Esc возвращает обычное окно.

- **ИГРАТЬ** запускает только клиент. Кнопка доступна после готовности сервера.
- **ЗАПУСТИТЬ СЕРВЕР** запускает Forge и затем Porthole для друзей. Клиент не открывается. Если Porthole не подключился, локальная игра остаётся доступной; кнопка предлагает повторить соединение.
- **ОТКЛЮЧИТЬ СЕРВЕР** отправляет команду сохранения и остановки, ждёт завершения Java и затем отключает Porthole. При долгом сохранении сервер не убивается принудительно.

Закрытие панели оставляет сервер работающим. Код подключения копируется отдельной кнопкой только после готовности Porthole. Запуск, сетевые проверки и чтение состояния выполняются вне потока интерфейса.

В настройках доступны язык, предел памяти сервера 2–8 ГБ и отключение проверки обновлений. Предел дополнительно ограничен половиной физической памяти. Без настройки сервер получает 2 ГБ при менее 12 ГБ RAM, 3 ГБ при менее 20 ГБ, иначе 4 ГБ. Начальная Java heap — 512 МБ. Это предел heap, а не всего потребления процесса; фактический расход зависит от модов и мира.

Архив **VM-Host-Tools.zip** содержит панель, скрипты, иконку и модуль проверки обновлений. Распаковывать поверх каталога уже настроенного сервера при закрытой панели. Мир, моды, аккаунты и личная конфигурация в архив не входят.

Требуется Python с Tkinter, доступные `python.exe` и `pythonw.exe`, настроенный Forge-сервер 1.12.2, Steam и Porthole. `run-server.py` ищет Java в `%LOCALAPPDATA%\Warfare-1.12.2\runtime`; другой путь можно передать через `VM_JAVA`. Серверный JAR должен называться `forge-1.12.2-14.23.5.2860.jar`.

Локальный `launch-warfare.py` рассчитан на существующий профиль Warfare-1.12.2 в `%APPDATA%\.minecraft` и выбранный аккаунт TLauncher. Он читает аккаунт только локально; никаких профилей аккаунтов в Git нет. Для отдельной чистой установки клиента используйте основной VM-Setup.zip.

```powershell
python warfare-launcher.py --check
pythonw warfare-launcher.py
```

На старте и при запуске сервера/игры выполняется фоновая проверка, если она включена. Настройка сохраняется в `.updates/preferences.json` как `autoCheck`; отсутствие настройки означает `true`. Если версия новее, появляется **Доступно обновление**. Нажатие открывает релиз. Серверные файлы и миры не заменяются автоматически.

Проверки панели: `python -X utf8 qa/test_host.py` из корня репозитория. Тесты используют изолированные временные каталоги и подмену внешних запусков.
