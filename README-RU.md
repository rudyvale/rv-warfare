## RV Warfare

RV Warfare — сборка Minecraft 1.12.2 про совместную игру на общем поле боя: техника, оружие, команды и собственный сервер для друзей. Интерфейс и полевая памятка доступны на русском и английском.

### Играть вместе

| Режим | Для чего |
| :--- | :--- |
| **Local** | Открыть одиночный мир без подключения к серверу и Steam. |
| **Friends** | Подключиться к другу по сохранённым данным. |
| **Owner** | Отдельное подключение к серверу владельца. |
| **Host my server** | Запустить отдельный сервер Forge, подключиться к нему и пригласить друзей. Мир сохраняется между сессиями. |

Для Porthole нужен работающий Steam. Прямой IP-адрес работает без Steam. На Windows режим **Host my server** сейчас показывает LAN-адрес или прямое подключение; автоматическая выдача кода Porthole не поддерживается.

### Начать игру

1. Скачай и распакуй полный архив **RV-Setup.zip**.
2. Запусти **INSTALL.cmd**, укажи игровой ник и нажми **Install**.
3. Нажми **Play / Играть** и выбери управление и подключение. Java входит в архив; установщику нужен интернет, чтобы скачать проверенные файлы.

На сервере стартовый набор выдаётся игроку автоматически при первом входе. Затем каждый игрок сам выбирает и пополняет снаряжение через **Меню → Набор**; администратору не нужно выдавать его каждому вручную. Если инвентарь заполнен, освободи слот и повтори запрос.

Команда выбирается в меню. Вернуться на общую площадку можно через **Меню → Spawn** или `/trigger spawn set 1`. Книга управления восстанавливается через **Меню → Книга** или `/trigger wbook set 1`.

### Что входит

- FPV-квадрокоптеры и самолёты «Герань» и FP-1.
- Техника MC Heli CE и Immersive Vehicles с наборами IAV/VEB, оружие Techguns, лечение и боевые звуки.
- Отдельная карта поля боя размером 2560 × 2560 блоков.
- Команды, меню, памятка и профили графики Low, Balanced и Quality.
- Лаунчер для Windows и экспериментальная сборка для Intel Mac.

Базовые меню техники проверены для указанных в сборке сценариев. Совместимость всего оружия между разными модами и каждой машины в нестандартных боях не подтверждена.

### Добавить БТР и другую технику

MC Heli CE позволяет подключать отдельные наборы техники. В наборе VEB 1.1.11 есть машина с названием `UBT-70 ShSR`, но это имя не подтверждает, что перед нами БТР; её работу в RV отдельно не принимали. Поэтому не обещаю эту модель как проверенный БТР. Если у тебя есть совместимый набор с разрешением автора, смотри [инструкцию по дополнениям](docs/VEHICLES.md): там описана установка на сервер и компьютеры всех игроков.
