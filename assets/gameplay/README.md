# Screenshot provenance

These six files are raw 1920 × 1080 Minecraft screenshots. They were captured in the same staged scene with shaders disabled or with `BSL_v8.2.09p2.zip` actually loaded. No image generation, retouching, cropping or post-processing was applied.

The scene uses the models and rendering code from the frozen RV 1.1.0 MC Heli build, SHA-256 `ea90ce380c54a45982b02f2ae61533517203e926da0f2d65d31e51d7dc3408bb`. The capture clients contained additional acceptance instrumentation; their complete JARs are not the production JAR. The images illustrate the aircraft and graphics settings, rather than verifying every file in the final release or the final world archive.

Capture used combat audio 1.4, SHA-256 `7a9dd2d0e05ecaaf8a610ad86c99b3e2b75d7555c154973da529c19b6cb959cf`. The final release uses audio 1.5, SHA-256 `5fddd87a99455edbd85005dd24851591862ab7d065e405597d2def4bc66d1937`, which changes the Apache burst event and leaves the visible models unchanged. A screenshot does not establish audio quality or measured FPS.
