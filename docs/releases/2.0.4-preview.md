# RV Warfare 2.0.4 Preview

RV 2.0.4 Preview pairs the Windows player package with an experimental Intel Mac client. The gameplay payload, world, aircraft, graphics and sound remain the same as RV 2.0.3 Preview.

## Downloads

- [Windows package — RV-Setup.zip](https://github.com/rudyvale/rv-warfare/releases/download/v2.0.4/RV-Setup.zip)
- [Intel Mac package — RV-Mac-Setup.zip](https://github.com/rudyvale/rv-warfare/releases/download/v2.0.4/RV-Mac-Setup.zip)

These links become available when the Preview release is published. The current stable update target remains RV 1.2.1.

## Play modes

- **Local** — open a local world without a server address or Steam/Porthole.
- **Friends** — join a friend's server using its saved connection.
- **Owner** — join the owner's server using a separately saved address.
- **Host my server** — start a separate Forge server, join locally and share its connection. The host world is preserved between sessions.

Friends and Owner keep independent destinations. Public packages contain no personal connection defaults.

## Mac compatibility

The package targets **Intel x64** and includes Java 8. Apple Silicon requires Rosetta 2. On Apple Silicon, Porthole is supported only through the official Steam installation.

This is an experimental preview. Native macOS GUI and Minecraft runtime acceptance is still pending; Windows checks do not establish that the Mac client launches or plays correctly on a Mac. Please include the Mac model, macOS version and reproduction steps when reporting an issue, and remove account or private connection details from logs.

The existing aircraft and battlefield images in the repository are genuine captures from the RV 1.1.0 scene. They illustrate gameplay content retained in RV 2.0.3 and 2.0.4; they are not Mac screenshots or evidence of Mac acceptance. See [screenshot provenance](../../assets/gameplay/README.md) and [RV 2.0.3 Preview menu captures](../gallery/README.md).

## Verified scope

Java 8 compilation, focused headless launcher checks and validation against the actual Mac package resources passed. The package contains the pinned Intel Java 8 runtime, three macOS native archives and the unchanged gameplay modules. Checks reject altered runtimes, download origins, preservation rules, launch scripts and used worlds.

Existing Mac game configuration is kept when playing again. The launcher checks the current Forge log and listening port before marking its own server ready, and requests a graceful save when stopping it. Windows and Mac use independent Friends and Owner destinations; neither is mandatory.

Native macOS GUI, in-game play and an external friend connection remain unverified. Existing advanced vehicle combat limitations from RV 2.0.3 still apply.
